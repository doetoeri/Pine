# 정책 차이 가시화와 지도 전용 모드 · 0.3.1

이 문서는 0.3.1 당시의 기록이다. 현재 모범안은 [0.3.2 전국 방재 모범안](NATIONAL_POLICY.md)의 100개 지자체·400개 정책으로 교체되었다.

## 구현

- 일시 홍수 기본 표시. 정책을 편집하거나 모범안을 적용하면 해일·차이·정책 구역을 함께 켠다.
- 실제 계산 셀의 영구 침수 → 해일 침수 → 상대 압력 차이를 순서대로 강조한다. 주황은 더 큰 영향·압력, 보라는 더 작은 영향·압력이다. 사진 명도를 낮춰 대비만 높이며 침수 면적과 계산치는 바꾸지 않는다.
- 침수 영향(영구 + 중복 없는 해당 연도 해일), 균등 분포 영향 인구, 일시홍수 피해 모형의 A/B 값과 감소·증가량 및 비율을 크게 표시한다. 경제활동 노출은 GDP 손실과 구분한다.
- 전력 공급 감소는 영구와 해일 셀의 합집합을 기존 가정 용량의 인접망 모형에 넣는다. 레이어 스위치는 수치를 바꾸지 않는다.
- 준공 전/동일 정책/기존 방재 유지에 따른 영구 침수 0을 설명한다. 정책별 착공 전·공사 중·효력 중·수명 종료를 표시한다.
- `효과 큰 해`는 같은 기후의 75개 계산 연도 중 침수 영향 면적 차이가 최대인 해를 명시적으로 선택한다. 면적 차이가 없으면 상대 압력 차이를 사용한다. 정책 적용 자체는 연도·카메라·기후를 바꾸지 않는다.
- `차이 지역 확대`는 현재 연도에서 차이가 계산된 행정구역으로 두 지도를 함께 확대한다.
- `지도만` 또는 M으로 정보 패널을 숨긴다. 연도·지도 이름·재생/복귀 조작만 남는다. 다시 M/Esc로 복귀하며 정책·연도·카메라와 재생을 유지한다.

## 모범 정책

`B 모범 정책`은 B만 변경한다. 각 편집기의 `모범 정책 적용`은 해당 정책안만 변경한다. 해당 목록을 예시로 교체하며 다른 정책안은 유지한다.

29개 정책, 총 자본비 **297.6억 유로**. 총 한도 400억 유로, 연간 한도 30억 유로. 기존 카탈로그의 비용·효과·설계/공사 기간을 사용한다. 공식 권고나 경제적 최적해가 아닌 수업용 예시다.

| 구성 | 지역 | 최초 준공 | 갱신 준공 |
| --- | --- | --- | --- |
| 방조제 6개 | Rotterdam, Amsterdam, Almere, Haarlemmermeer, Dordrecht, Zaanstad | 2041 | 수명 내 |
| 배수 3개 | Rotterdam, Amsterdam, Almere | 2034 | 2069 |
| 전력시설 방수 3개 | 같은 3개 지역 | 2035 | 2070 |
| 송전 우회 2개 | Rotterdam, Amsterdam | 2039 | 2084 |
| 교통 보강 2개 | 같은 2개 지역 | 2039 | 2089 |
| 신도시 1개 | Apeldoorn | 2038 | 수명 내 |
| 이주 2개 | Rotterdam·Almere → Apeldoorn | 2040 | 총 6만 명 |

정책 구역은 실제 행정경계이지만 모형이 정책을 적용하는 범위다. 실제 공사 위치·제방 선형·보호 면적을 측량한 값이 아니다. 지형과 기후 자료는 변경하지 않았다.

## 검증

- TypeScript + Vite production build 통과. 자산 `index-hgX4_bBo.js`, `index-9125Af1H.css`. 복구 전 통과한 빌드와 일치하고 복구 후 검사를 다시 수행했다.
- 단위 검사 **27 passed**, 0 failed. [원본 기록](policy-effects-unit.txt).
- Playwright **20 passed**, 0 failed, 0 skipped, 0 flaky. [원본 JSON](policy-effects-playwright.json).
- A/B 독립 적용·복제 동일 결과·저장·연도와 카메라 보존, 예산·수명 갱신·이주 수용 선행조건 통과.
- Canvas 픽셀에서 주황/보라 차이 표시를 확인하고 동일 정책 복제 후 해당 차이 색상이 사라짐을 확인했다.
- 1920×1080 및 3840×2160 실제 viewport에서 섹션·표·감소량 카드의 가로/세로 잘림 검사 통과. 지도 전용 모드의 지도는 화면 98% 이상을 차지한다.
- M/Esc 복귀와 재생 유지, 이벤트/재개, 카메라 동기화, 전체화면·단축키, WebGL fallback·내륙 국경, PinCon 루트/next HTTP 200 검사 통과.
- 시스템 시계를 181/361/541/602초로 이동해 4개 발표 챕터와 자동 반복을 확인했다. 이 버전의 10분 실시간 재검사는 미실시다. 이전 0.3.0의 612초 기록은 MISSION03_TEST_REPORT.md에 남아 있다.

### 같은 KNMI 고배출 조건의 모형 예시

새 정책 없는 A와 모범안 B의 면적 차이가 최대인 연도는 **2096년**이다. 영구 침수는 양쪽 0이며 아래 면적·인구는 해당 연도 해일 모형 결과다. 실제 재난 발생 또는 피해 회피량 예측이 아니다.

| 지표 | A | B | B에서 감소 |
| --- | ---: | ---: | ---: |
| 해일 침수 면적 | 16,551.6km² | 15,677.3km² | 874.3km² (5.3%) |
| 해일 영향 인구 | 1,067.3만 명 | 853.8만 명 | 213.6만 명 (20.0%) |
| 일시홍수 피해 · 가정 | 5,190.3억 유로 | 3,909.8억 유로 | 1,280.5억 유로 (24.7%) |
| 공급 부족 · 가정 | 6,320MW | 4,623MW | 1,696.9MW |

실물 TV 측정과 과학 모형의 물리 보정은 미검증이다. 루트/next의 HTTP 검사는 모든 로그인/Firebase 사용 흐름의 검증을 뜻하지 않는다.
