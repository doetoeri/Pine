# NETHERLANDS 2100 · Model 0.1

실제 GIS 위에서 작동하는 재현 가능한 탐색 모형이다. 네덜란드의 공식 수리모형, 실제 정전 예측, 디지털 트윈의 검증된 국가 운영모형이 아니다. 수치는 어떤 가정을 적용하면 어떤 차이가 나는지 설명하는 연구 실험이다.

## 1. 확보한 자료와 공간 단위

- CBS 2024 육지 행정구역 342개. 관측 인구 합계 17,942,942명. 2026 관측 인구로 바꾸어 부르지 않는다.
- AHN DTM 서비스에서 35,951개의 유효 고도를 **최근접 1km 간격**으로 받았다. 전국 원본 0.5m DEM을 다운로드한 것이 아니다.
- 2×2 표본의 중앙값을 2km 분석 셀로 만들고 CBS 행정구역 중심점 판정으로 연결했다. 유효 분석 셀 8,747개. 2km 셀 내부의 고도·주거 차이는 해결하지 못한다. 누락 지역은 `model.meta.missingMunicipalities`에 남긴다.
- CRS: 원본 고도 EPSG:28992 / NAP(m); 브라우저 GeoJSON CRS84 경도·위도. 100m 경계 단순화는 지도와 인접관계 계산에 적용한다.
- OSM 5개 지역 범위에서 실제 시설 25개와 도로·철도·송전·방재 선분 464개를 추출했다. 시설의 정확한 계통 연결·진입 수위·실내 높이는 알 수 없다. 건물/부지 중심점은 원본 기하의 꼭짓점 평균으로 근사했다. 전국 시설 목록이라고 표시하지 않는다.

## 2. 해수면 기준과 시간 경로

KNMI’23 API의 표제 기준은 일반적으로 1991–2020이나, **해수면 각주는 1995–2014**이다. 원본 API JSON과 각주의 짧은 발췌·출처를 포함했다.

|시나리오|2050 중앙 / 범위 (m)|2100 중앙 / 범위 (m)|
|---|---|---|
|L|0.24 / 0.16–0.34|0.44 / 0.26–0.73|
|H|0.27 / 0.19–0.38|0.82 / 0.59–1.24|

관측 기반 NAP 연결값을 확보하지 못해 기준기간 평균 해수면을 **0.00m NAP로 가정**했다. 실제 NAP와 기준기간 평균이 같다고 주장하지 않는다. 2026년 변화량은 2005년을 대표 기준점으로 하여 3mm/년 × 21년 = 0.063m로 가정한다. 2026–2050, 2050–2100을 각각 선형 보간한다. 연도별 값은 KNMI 공식 시계열이 아니다. STRESS는 2100년 2.50m라는 별도 가정이며 KNMI 확률 구간이 아니다.

KNMI의 배경 지반운동과 이중 계산하지 않도록 추가 국지 지반침하는 기본 0mm/년이다. 설정값을 바꾸면 2026년부터 DEM에 추가 침하를 적용한다.

## 3. 폭풍과 지형 연결성

매년 하나의 가정 폭풍·조석 수위 `S = scale × [1 + 2.4u^4]m`를 생성한다. `u`는 연도와 정수 시드로 만든 결정적 균등 난수이다. 실제 관측 폭풍 자료로 적합하지 않았고 재현기간·확률로 해석할 수 없다. 같은 기후 입력과 시드를 A/B/C가 공유한다. 특정 연도의 홍수는 미리 정한 연출이 아니라 이 입력과 상태 임계값에서 생긴다.

해양과 연결된 외부 NoData를 서·북쪽 경계에서 flood-fill한다. 바다에 인접한 표본에서 4방향 최소최대 고도 경로(priority flood)로 셀의 지형 유입 문턱(spill)을 계산한다. 내륙의 고립 NoData 구멍은 바다로 취급하지 않는다. 제방·하천·수문·호수는 2km 해상도에서 해결하지 못한다. 북·서 해안 씨앗 선정은 근사이며 검증되지 않았다.

모든 지역의 기존 보호 한계는 **가정 3.2m NAP**로 둔다. 이는 실제 제방고도·폐쇄 수위·보호빈도가 아니다. A는 이 보호 성능이 기존 유지관리로 일정하게 보전된다고 가정한다. 기존 유지관리의 공통 비용은 확보하지 못해 A/B/C 모두 비용에서 제외한다.

`eventWater = assumedBaseNAP + seaLevelChange + assumedStormTide`

침수는 사건 수위가 해당 지역의 보호 문턱과 셀의 지형 유입 문턱을 모두 넘을 때만 허용한다. 임시 수심은 `max(0, 0.35 × (eventWater − subsidedDEM) − drainage)`이다. 계수 0.35는 유한 사건 지속시간을 표현하는 가정이며 동수역학 계산이 아니다. 피해 셀 기준은 수심 0.1m 초과이다. 보호 문턱을 행정구역별로 독립 적용하므로 지역 간 제방 우회와 역류를 재현하지 못한다.

네 레이어: (1) 단순 저지대, (2) 보호를 적용하지 않은 지형상 잠재 노출, (3) 현재 사건 침수, (4) 선택 정책 후 잔여 사건 위험. 보호시설이 있으므로 저지대와 사건 침수는 다르다.

## 4. 정책, 공사와 인구

9개 정책의 비용·기간·효과·수명·탄소는 `src/model.ts` CATALOG와 ASSUMPTIONS.csv의 가정이다. 지역 전체 적용이며 개별 실제 공사 위치는 아니다. 설계/인허가/건설을 합친 뒤에 효과가 생긴다. 입력한 추가 지연은 준공을 늦춘다. 공사 중에도 해수면과 폭풍은 매년 계속 계산한다. 자동 확률적 공사 지연·부분 준공은 미구현이다. 수명이 끝나면 신규 시설 효과를 제거하며 노후화 곡선은 없다.

비용은 설계·공사·지연 기간에 균등 지출한다. 총 자본예산과 연간 자본예산을 검사한다. 연간 유지비는 별도 운영비로서 자본예산 한도에 포함하지 않고 총비용에 포함한다.

신도시 완공은 도착지의 신규 수용인구 60,000명을 만든다. 이주 정책은 신도시가 먼저 완공된 경우만 허용한다. 이주는 최대 30,000명이며 완료 시 출발지에서 빼고 도착지에 같은 인원을 더한다. 이는 수년에 걸친 단계별 실제 이주 일정을 모델링한 것이 아니라 완료 시점의 집계다. 여유 수용인구를 넘을 경우 가능한 수만 이동한다. 출생·사망·국제이민은 제외하여 국가 총인구를 보존한다.

## 5. 전력과 시설의 연쇄 영향

OSM 시설 위치는 실제지만 전기 계통 데이터는 아니다. TenneT 자산 메타데이터는 확인했으나 모든 권리 유보여서 원본 자산망을 배포하지 않는다.

전력 실험은 실제 행정구역 인접 그래프 817개 변에 **가정 수송 용량**을 얹은 별도 지역 모형이다. 각 지역 수요는 0.6kW/인, 정상 지역 공급은 수요의 1.25배, 인접 변 용량은 두 수요 중 작은 값의 45%이다. 홍수 피해비율에 따라 공급을 감소시키며 방수 보강과 이중화는 각각 공급 저하·우회 용량을 개선한다. Dinic 최대유량은 대체 공급경로를 계산하므로 하나의 공급원이 줄었다고 모든 지역을 자동 정전시키지 않는다. NetworkX로 작은 검증망의 최대유량을 교차 확인했다.

이 그래프는 AC/DC 전력조류, N−1, 실제 케이블 연결, 계통 운영, 수입 전력, 개별 발전소 출력이 아니다. OSM 발전소·변전소의 정지 배지는 도시 평균 수심에 따른 취약성 예시이며 전력 공급망에 직접 연결하지 않는다. 도로·철도·항만 단절 경로 분석은 미구현. 지역 물류 개선 정책은 손실 계수만 조정한다.

## 6. 경제 회계와 단위

실제 지역 GDP를 확보하지 못했다. `economicActivity = population × €55,000/person-year`를 대체지표로 사용하고 항상 가정으로 표시한다. 2024년 주택수 × CBS 평균 주택가액을 주거 자산의 출발점으로 한다. 기타 기반시설은 주거 자산의 30%라는 가정이다. 실제 국가 자산목록은 아니다. 자산 손상 비율은 `min(0.6, meanDepth × 0.12)`.

- 자산 피해 = 가정 자산 × 피해 셀 비율 × 손상 비율. **복구비는 이 항목에 포함된 것으로 처리하여 별도 더하지 않는다.**
- 생산 손실 = 경제활동 × 피해비율 × 30/365 + 비침수 생산분 × 전력 부족비율 × 72/8760. 전력으로 인한 손실은 이미 침수 중단으로 계산한 부분에 다시 적용하지 않는다.
- 총비용 = 자산 피해 + 생산 손실 + 정책 초기 지출 + 정책 유지비.
- 반복 사건 뒤 자산은 다음 연도에 완전 복구된다고 가정한다. 주택 자산은 이주 뒤에도 소유 자산으로 남는다. 2024년 화폐가치와 실질 비용 가정을 고정하고 인플레이션/성장/행동 적응은 반영하지 않는다.
- 정전 시간은 해당 연도 최대 지역 공급부족비율 × 72시간이라는 지표이며 관측 정전 시간이 아니다.
- 탄소는 정책 내재탄소와 신도시 가정 운영절감 6kt/년을 별도 kt CO₂e로 집계한다. 홍수·국가 전력·생애주기의 전체 탄소는 아니다.

## 7. 최적화

Python OR-Tools CP-SAT. 피해가 큰 상위 24개 행정구역 × 3정책(제방/생태/전력보강) × 3착수 시점(2026/2036/2046), 총 216개 후보. 동일 난수 시드 2100/2117/2143의 피해 회피 NPV 평균에서 정책 자본비·유지비 NPV를 뺀 한계편익 대리 목적함수를 사용한다. 할인율은 3%, 단위는 일정 유로의 billion이다. 현금흐름 단위가 같아 별도 지표 정규화가 필요하지 않다.

총 자본 €40B, 연간 자본 €3B와 지역당 최대 하나의 선택을 제약한다. 공사기간·수명·착수 시점이 편익과 지출 일정에 반영된다. 216개 중 선택된 조합은 전체 비선형 침수·전력 모형으로 다시 평가했다. CP-SAT의 OPTIMAL은 **한계편익 선형 대리모형**에만 적용되며 전체 모형의 전역 최적해는 보장하지 않는다. 법적 토지이용·생태 보호구역·사회적 부담·강제이주·탄소 다목적 최적화는 미구현이다. 이주와 신도시 선후관계는 사용자 정책 검증에만 반영한다.

C 화면은 이 저장된 해를 재생한다. 기후·예산을 바꾸면 저장된 정책을 그 입력 아래 재평가할 뿐 자동 재최적화하지 않는다. 새 계산은 Python 명령 또는 로컬 API로 수행할 수 있다.

## 8. 재생과 지도

모든 연도는 같은 입력으로 처음부터 순서대로 계산한 고정 배열이다. 스크러빙/되감기/시나리오 전환에 의해 결과가 달라지지 않는다. 이벤트 ID는 종류·연도·위치에 대해 결정적이다. 이벤트 전체 로그를 보존하며 재생은 중요도 필터 뒤 **연도당 우선순위 상위 3개**만 자동 정지한다. 같은 연도 큐, 검토 완료 ID, 연도 건너뛰기로 중복 재팝업을 막는다. 시나리오·가정·정책을 바꾸면 검토 상태를 초기화한다. 수동 이전 이벤트 이동은 다시 검토하려는 의도로 허용한다.

MapLibre GL JS가 기본이다. WebGL이 없으면 같은 실제 GeoJSON을 Web-Mercator로 그리는 SVG 2D 대체 지도다. 온라인 CARTO 타일이 실패해도 국가 경계와 계산 결과는 번들로 표시한다. 3D는 실제 AHN 표본을 재투영한 지형 타일이며 수직 과장은 18배, 시각화 전용. WebGL 없는 환경에서 3D는 지원하지 않는다. 3D 시각화의 NoData는 평탄 처리하지만 분석 결측은 그대로 유지한다.
