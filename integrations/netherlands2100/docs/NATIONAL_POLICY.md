# 전국 방재 모범안 · 0.3.2

기존 6개 도시·29개 정책 예시를 **100개 지자체·400개 정책**으로 교체했다. 코드 커밋: `12ff0ab69a57ea66da2c44971304b27ededba1af`.

## 사용

1. [운영 사이트](https://pincon.app/climate/)에서 `B 모범 정책`을 누른다. 기존에 저장한 29개 정책도 이 버튼을 다시 누르면 새 모범안으로 교체된다. 사용자 정책을 자동으로 덮어쓰지는 않는다.
2. `3 방재 실패 시연`과 `2100`을 선택한다. 정책 없는 A와 전국 방재 모범안 B를 비교한다. A에 기존 정책이 있으면 `A 초기화`로 비울 수 있다.
3. `지도만` 또는 M으로 지도 전용 화면을 사용한다. M/Esc로 조작 화면에 돌아온다.

정책 적용 자체는 현재 연도·기후·카메라와 반대편 정책을 유지한다. 편집기의 `모범 정책 적용`은 해당 쪽만 교체한다. 계산된 침수를 보도록 잠재 위험은 끄고 일시 홍수·차이 강조·정책 구역을 켠다. 기후를 바꿔도 선택한 레이어 조합을 유지한다. 잠재 위험은 언제든 다시 켤 수 있다.

## 구성과 근거

정책이 없는 방재 실패 시연의 2100년 **영구 침수 + 해당 연도 일시 홍수 면적**이 큰 순서로 100개 지자체를 선택했다. CBS 행정코드로 고정하므로 적용 당시 A/B 정책·기후·연도에 따라 대상이 바뀌지 않는다. 지자체 전체를 공사 면적이나 실측 보호 면적으로 해석할 수 없다.

각 지자체에 다음 네 정책을 넣는다. 기존 카탈로그의 비용·공사 기간·효과·수명을 그대로 사용한다.

| 정책 | 착공 → 준공 | 지자체당 자본비 | 모형의 역할 |
| --- | --- | ---: | --- |
| 생태 기반 해안 보호 | 2026 → 2034 | 4억 유로 | 방조제 준공 전 조기 방어 |
| 제방 증고 | 2026 → 2036 | 12억 유로 | 가정 방어 한계 보강 |
| 방조제 확충 | 2026 → 2041 | 28억 유로 | 장기 방어 |
| 제방 갱신 | 2086 → 2096 | 12억 유로 | 첫 제방의 2096년 수명 종료와 동시에 대체 |

총 자본비 **5,600억 유로**, 총 예산 한도 **6,000억 유로**, 연간 한도 **400억 유로**다. 자본비와 유지관리비는 별도다. 실제 사업 타당성·인구 피해 최소화·비용 효율을 최적화한 계획은 아니다.

## 같은 조건의 2100년 결과

공유 조건: 방재 실패 시연, 해수면 +2.50m, 난수 seed 2100, 기존 해일 입력. A는 추가 정책 없음, B는 위 모범안이다. 해일 면적은 영구 침수와 중복되지 않는 해당 연도 셀이다.

| 지표 | A | B |
| --- | ---: | ---: |
| 영구 침수 | 15,067.96481km² | 1,918.04596km² |
| 해당 연도 일시 홍수 | 2,223.391404km² | 711.343083km² |
| 합계 침수 영향 | 17,291.356214km² | 2,629.389043km² |
| 두 침수 모두 없는 분석 육지 | 44.64% | **91.58%** |

침수 영향 면적은 약 **84.8% 감소**한다. 분모는 모형 분석 육지 31,235.093742km²이며 네덜란드 공식 국토 전체 면적과 동일한 값으로 주장하지 않는다. 실제 지형·기후·방어 효과 계수·침수 계산 엔진은 수정하지 않았다.

이 결과는 단순화된 시연이다. 극단 모드에서는 활성 방어 증고가 있는 지역의 영구 방재 실패를 막는 가정이 사용된다. 실제 수리·제방 신뢰성 검증을 거친 방재 성공률이 아니다. 해일은 별도 방어 높이와 비교한다. **2100년의 결과가 2026~2100년 내내 91.58% 안전함을 뜻하지 않는다.** 준공 전에는 큰 해일 피해가 남는다. A도 고지대까지 모두 잠기지는 않는다.

## 검증

- TypeScript + Vite 빌드 통과. [원본](national-policy-build.txt).
- 단위 테스트 **28/28 통과**. 100개 지자체의 기준 순위, 400개 고유 정책, 예산, 기존 공사 기간, 방어 공백 없는 제방 갱신, 고배출·극단 모드 결과, 입력 지형·기후 불변을 확인했다. [원본](national-policy-unit.txt).
- Playwright **20/20 통과**, 실패·건너뜀·flaky 0. [JSON](national-policy-playwright.json), [로그](national-policy-playwright.txt).
- A/B 독립성·저장·동일 정책 동일 결과, 2080년 적용 시 연도·카메라 보존, 실제 Canvas 차이 색상 및 동일 정책 후 색상 제거를 검사했다.
- 전국 모범안의 2100년 결과를 1920×1080·3840×2160에서 확인했다. 섹션 겹침·표와 결과 카드 잘림 검사, 지도 전용 98% 이상 면적과 M/Esc 복귀를 통과했다.
- 400개 정책을 유지한 채 시스템 시계를 이동하는 가속 검사로 600초의 4개 챕터와 자동 반복을 확인했다. **이번 버전의 실제 10분 실시간 연속 재생은 미검증**이다.
- PinCon 루트/next 경로와 기후 자원의 독립 경로 검사를 통과했다. 로그인/Firebase 전체 흐름이나 실물 TV는 재검증하지 않았다.

Playwright의 첫 시도는 테스트용 Chromium 실행 파일이 없어 페이지를 열기 전에 실패했다. 공식 배포본 설치 후 위 20개를 전부 다시 실행했다.

## 운영 배포 확인

[GitHub Pages 배포](https://github.com/doetoeri/Pine/actions/runs/40621007189)가 성공했다. 운영 HTML·JavaScript·CSS가 저장소와 바이트 단위로 일치했고, 기존 PinCon `/`·`/next/` 응답도 수정되지 않은 저장소 파일과 같았다. [HTTP·배포·브라우저 기록](NATIONAL_POLICY_DEPLOYMENT.json).

운영 브라우저에서 B만 400개 정책 적용 → 2026년 유지 → 방재 실패 시연·2100년 선택 → A 0개/B 400개와 위 침수 결과 → 지도만 보기와 복귀를 확인했다. 연도·정책·동기 카메라가 유지되었다. 운영 브라우저 해상도는 1363×936이며 FHD/4K는 위 별도 Playwright 검사다.
