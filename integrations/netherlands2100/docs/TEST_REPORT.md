## Playwright 실제 확인

- 1920×1080 / 3840×2160: 지도 표시, 타임라인 가시성, 가로 overflow 없음. 한국어 웹폰트를 포함하고 실제 화면을 내부 확인했다.
- 타임라인 스크러빙과 키보드 1년 이동.
- 8× 재생 시 임계값 사건으로 2029년 자동 일시정지, 동일 연도 다음 큐, 연도 건너뛰기 후 재팝업 방지.
- 키보드 A/B/C 전환과 A/B 분할 지도의 동일 연도.
- 정책 추가, 준공 연도 표시, 잘못된 이주 선후관계 거부.
- 영어 UI, 출처 패널.
- 실제 Fullscreen API 진입과 Escape 종료.
- 온라인 basemap 요청을 중단해도 저장된 실제 GIS 표시.
- WebGL 컨텍스트를 명시적으로 비활성화해도 실제 GIS 2D 대체 지도 표시.
- 3D AHN 토글과 침수 레이어 전환.
- 모델 파일 HTTP 503일 때 다시 시도 가능한 오류 화면.

## 모델과 API 확인

- 공식 KNMI 앵커·범위, NAP와 기준기간, 실제 출처와 인구 총합.
- A/B 동일 해수면·폭풍 입력.
- 준공 이전 보호 효과 없음, 공사 중 홍수, 해수면 상승 지속, 입력 지연에 따른 준공 지연.
- 대체 경로가 있는 공급 수송망 최대유량을 NetworkX로 독립 교차 검사.
- 이주 전후 국가 인구 총량 보존과 도착지 수용력·신도시 선후관계.
- 반복 실행 결정성, 이벤트 ID 중복 없음.
- 자산 피해·생산 손실·투자·유지비의 비용 합계와 누적 일관성.
- 총/연간 예산 및 중복 정책 ID 거부.
- CP-SAT 선택 조합의 예산과 전체 모형 재평가.
- FastAPI health/75년 실행 결과, 잘못된 정책 HTTP 422.

실행 원본: playwright-results.json / pytest-results.xml. Starlette TestClient가 httpx 사용 중단 예고 경고 1개를 냈으나 검사는 통과했다. 초기 개발 중 발견된 렌더링 반복과 Fullscreen Escape 문제는 수정 후 검사했다.

## 검증하지 못한 것

외부 수리모형/관측 침수·실제 발전소 정지·계통 운영·지역 GDP와의 수치 적합도는 검증하지 못했다. 브라우저 동작·수식·일관성 테스트 통과는 물리적 타당성 입증이 아니다. Apple Safari·TV 내장 브라우저·실제 발표장 프로젝터의 실기기 시험은 수행하지 않았다. 기본 브라우저는 WebGL이 꺼져 있었으므로 그 환경에서는 2D 대체 지도를 확인했고, Playwright Chromium에서는 MapLibre와 3D를 별도로 검사했다.
