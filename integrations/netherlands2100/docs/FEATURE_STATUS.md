# 기능별 실제 구현 상태

|기능|상태|범위와 제한|
|---|---|---|
|React/TS/Vite/MapLibre/Tailwind/Recharts/Zustand|완료|실제 빌드·구동|
|전국 실제 행정구역·인구·주택 GIS|완료|CBS 2024, 342개|
|실제 AHN 고도 확보|완료|0.5m 서비스에서 1km 표본 취득, 2km 분석|
|KNMI 공식 시나리오|부분 구현|2050/2100 공식 앵커·범위, 연간 경로/2026값은 가정|
|NAP/기후 기준기간 구분|완료|해수면 1995–2014; NAP 관측 연결값 미확보 명시|
|2D/3D·확대/이동·지역 선택|부분 구현|MapLibre+AHN 3D; WebGL 없으면 실제 GIS 2D|
|Full HD/4K·전체화면·한국어/영어|완료|키보드, 화면 자동 축소, 패널 접기|
|지형상 저지대·잠재·사건·잔여 레이어|부분 구현|분리됨; 2km 지형 연결성·가정 보호 한계|
|정밀 수리모형/제방 실제 성능|미구현|검증 자료·실제 제방고/수문 운영/역류 없음|
|실제 발전/변전/병원/철도/방재시설|부분 구현|OSM 5개 표본 범위, 25개 시설/464 선분|
|전국 실제 전력계통 연쇄 피해|미구현|실제 연결·용량·운영자료 미확보|
|대체 경로 있는 지역 공급 수송모형|부분 구현|실제 인접 그래프 + 가정 용량, 최대유량 검증|
|교통/항만/물류 네트워크 단절|미구현|지역 생산 손실 계수만 조정|
|임계값 자동 정지 이벤트|완료|같은 연도 큐, ID 중복 방지, 우선순위, 이전/다음, 카메라|
|9개 정책·건설기간·수명·유지비|부분 구현|비용·효과·기간 가정, 자동 지연은 없음|
|공사 중 홍수와 준공 후 효과|완료|지연 입력도 반영; 완공 전 효과 0|
|이주 인구/신도시 수용력|부분 구현|집계 완료시 이주, 총량 보존·선후관계 검증|
|실제 GDP·실제 국가 피해 예측|미구현|대신 가정 경제활동 대체지표 명확히 표시|
|비용 회계·인구·탄소·전력 결과|부분 구현|가정값, 복구비 이중합산 안 함|
|A/B 동기화 비교|완료|연도·카메라·기후 입력 동기화|
|다기간 OR-Tools 최적화|부분 구현|216후보/3시드/예산 제약, 선형 대리모형만 최적성 검증|
|법규/환경/사회부담/탄소 다목적 최적화|미구현|실제 제한 데이터 미확보|
|로컬 FastAPI|완료|동일 엔진 재사용, 입력 검증, 결과/최적화 API|
|호스팅 Python 상시 서버|미구현|배포본은 정적 앱+사전계산 C, B는 브라우저에서 계산|
|출처·가정·재현 스크립트·전체 ZIP|완료|원본 스냅샷과 해시, 설치·시연 설명 포함|

PHASE 1은 작동하는 GIS 발표 시스템으로 구현했고, PHASE 2–5는 위 간이모형의 범위 안에서 작동한다. 검증된 국가 수리·전력·경제 디지털 트윈으로 부르지 않는다.
