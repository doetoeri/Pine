# 문장노트

PinCon의 `/eng/`에 배치하는 로컬 우선 영어 지문 학습 웹앱입니다. 처음 열면 앱 사용법을 익힐 수 있는 창작 예시 지문 세 편이 들어 있습니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 실행합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 Chrome 또는 Edge에서 엽니다. 배포 빌드는 다음과 같이 실행합니다.

```bash
npm run check
npm test
npm run build
npm run preview
```

`dist`를 HTTPS 정적 호스팅이나 로컬 HTTP 서버에서 제공할 수 있습니다. 실행 파일을 직접 내려받은 경우 Python 3가 있는 Windows에서 `py -m http.server 4173 --directory dist`를 실행하고 `http://localhost:4173`을 여는 방법도 있습니다. 설치용 서비스 워커는 배포 빌드에서 등록됩니다.

## 학습 흐름

1. 지문 라이브러리에서 **새 지문**을 눌러 영어 원문을 붙여넣습니다.
2. 원문에서 표현을 선택하고 **주석 추가**를 누릅니다. **S Pen 선택**을 켜면 펜으로 그은 뒤 바로 주석을 쓸 수 있습니다. 모드는 다시 끌 때까지 유지됩니다. 켜져 있는 동안 원문은 손가락 터치를 무시하고, 왼쪽 스크롤 띠에서 화면을 움직일 수 있습니다.
3. 질문 한 칸에 궁금한 점을 적습니다. 필요하면 **유형·구분법**을 열어 유형, 이유, 나만의 구분법을 덧붙입니다.
4. **모아보기 → AI 프롬프트 복사**의 내용을 AI 채팅에 붙여넣습니다. 응답으로 받은 `munjang-note-ai-answers.json`을 **AI 답변 불러오기**로 가져옵니다.
5. **PDF 출력**에서 지문별 분석집이나 유형별 정리집을 선택합니다. 출력 범위의 **AI 답변 포함**을 체크하면 답변이 ‘AI 참고 해설’로 표시됩니다. 빈칸·서술형 시험지에서는 해설에 포함됩니다.

원문 편집 과정에서 위치를 확정하기 어려운 주석은 ‘위치 확인 필요’로 바뀝니다. 해당 주석에서 **범위 다시 선택**을 눌러 새 위치를 연결할 수 있습니다. 키보드 범위 선택은 지문 옵션에 있습니다.

## 저장과 백업

정적 React 앱이며 원문, 주석, 유형, 시험 범위, 복습 기록을 IndexedDB의 별도 저장소에 기록합니다. 주석은 지문 ID, 원문 범위, 문장 ID, 선택 문자열과 앞뒤 문맥을 함께 저장합니다. 지문과 학습 기록을 사용하는 외부 요청은 없습니다.

**설정 → 데이터 백업**에서 버전이 있는 JSON 파일을 내보내거나 불러옵니다. 복원은 유효한 백업이 확인된 뒤 사용자가 확인 버튼을 누르면 현재 브라우저 데이터를 교체합니다. 배포 주소와 로컬 주소에는 각자의 저장 공간이 생깁니다. 기기나 주소를 바꿀 때 JSON으로 자료를 이동하세요.

## 기술 구성

React, TypeScript, Vite, IndexedDB, Zod, pdf-lib, Fontkit을 사용합니다. PDF는 브라우저에서 직접 생성합니다. 한영 PDF는 자주 쓰는 문자 범위로 준비한 Noto Sans KR 글꼴을 내장해 서로 다른 PDF 뷰어에서 읽고 검색할 수 있습니다. 글꼴 사용 조건은 `public/fonts/LICENSE-Noto.txt`에 있습니다.

AI 답변 파일은 `format`이 `munjang-note.ai-answers`이고 `version`이 `1`인 JSON입니다. 각 답변의 주석 ID와 내용 확인 키가 저장된 주석과 일치할 때 해설, 구분법, 필요한 문맥을 별도로 저장합니다.

## PinCon 배포

이 폴더에서 `npm ci`와 `npm run build`를 실행한 뒤 `dist`의 내용을 PinCon 저장소 루트의 `eng`에 배치합니다. 최종 URL은 `https://pincon.app/eng/`입니다. 서비스 워커와 홈 화면 설치 범위는 `/eng/`를 기준으로 합니다.
