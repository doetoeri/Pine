## 실제 지리와 가상 자료

17개 **고정 연구권역**, 100거점(공급18·수요82)이다. 새96거점은 모두 가상 명칭·생성 좌표로 표시했고, 기존 인천4기관의 실제 명칭·주소·근사 좌표를 보존했다. 경계는 geoBoundaries/Natural Earth2021년 자료이며 최신 법정 행정구역이나 실제 전국 기관 수를 뜻하지 않는다. 광주·전남은 연구권역으로 분리했고2023년 군위 편입 등의 최신 경계 변화는 재현하지 않는다.

## 지도503 조사와 수정

사용자가 관찰한 원래503의 요청 URL/HAR는 확보하지 못했고 이 환경에서 원래 오류를 재현하지 못했다. 현재 브라우저의 기준버전 OSM타일10개는 모두256px로 표시됐고, 개선버전의 실제 OSM타일15요청은200응답·재시도0이었다. 브라우저가 읽을 수 있는 Content-Type/Cache-Control/Expires도 기록했다. 별도 HTTP진단은 PinCon `/bloodflow/`404, OSM타일200, OSRM200이었다. 이 응답을 사용자 당시 네트워크 장애의 원인으로 단정하지 않는다.

기존 서비스워커가 같은 출처의 미캐시 네트워크 실패에 자체503을 만드는 코드를 발견했다. 개선판은 앱 캐시 실패를504와 `X-Bloodflow-Offline: app-cache-miss`로 구분한다. 타일의 img 오류만으로503을 추측하던 방식 대신 CORS fetch로 실제 응답 상태·허용된 헤더를 기록한다. CORS/네트워크 오류는 상태미확인으로 남긴다.

온라인 타일은 사용자 선택 시 현재 화면만 요청한다. 동시4개·분당32회·세션80회 한도, 동일 URL중복 방지, 화면 밖 대기 요청 취소, 요청별 최대2회 지수 백오프 재시도, 연속3실패 회로 차단과60초 수동 재연결 대기를 사용한다. 403/429는 재시도·우회하지 않는다. 기본 HTTP캐시와 Referer를 유지하고 공개 타일을 사전 다운로드·오프라인 배포하지 않는다. 실패 시 저장된 경계·도로를 표시하며 시뮬레이션은 독립적으로 진행한다.

실제 브라우저의 **합성 테스트**: 503을1회 반환한 경우16요청 중15성공·재시도1회 후 회복했다. 계속503을 반환한 경우4요청·재시도2회에서 중단하고 벡터 지도로 돌아왔으며 +6시간 계산이 계속됐다. 합성 응답에는 `X-Bloodflow-Fixture: synthetic-503`을 표시했다. 이는 공공 지도 서버에서 실제503을 재현했다는 의미가 아니다. 자세한 URL·헤더·정책·한계는 `docs/MAP_503_ANALYSIS.md`에 있다.

## 실험과 생명과학 통합

N실험은 A지역내부, B인접권역, C전국통합을 같은 시드·초기재고·생물학적 조건·기간으로 계산한다. 기존 A안전재고·B수요변동·C제제/수명/적합성 실험도 남겼다. Biology는 전국 권역별 공급 가능량·보류·임박 재고·실제 도착 유입을 관찰하고, 제제·조건 설정과 반복 실험에 독립적으로 참여한다.

KRC선택 제제와 Lifeblood적합성 자료를 다시 확인했다. 온도는 합성 기록이며 이탈은 보류를 만든다. 임의의 생존율·품질 저하 공식은 없다. 혈소판 동일형 가정과 임상적 예외·해동 생략을 표시했다. 연구자가 두 해석·가설·한계를 직접 기록하며 보고서 자동 대필 기능은 만들지 않았다.

전국 부족률=부족/요청, 폐기율=(만료+제외)/(초기재고+외부입고)다. 권역 폐기는 권역 생성+실제 도착 유입을 분모로 삼는다. 권역 운송량은 출발 적재 수량이다. 평균·표본SD(n−1)·Student t95%구간과 같은 시드의 B−A/C−A차이를 제공한다. 종료 시 남은 운송·재고를 공급이나 폐기로 강제 처리하지 않는다. 저장된 결과의 당시 조건과 현재 세계의 차이를 명시한다.

예제 N실험은14일×6반복×3정책=18회 실행했다. 모든 보존·수요 fingerprint가 일치했다. 반복 평균 부족률은 A25.83%, B25.66%, C31.14%, 폐기율은 A9.58%, B9.62%, C10.51%였다. 전국 통합이 항상 우수하다고 결론짓지 않는다. 이 값은 가상 자료·명시한 탐욕적 정책의 예시이며 실제 한국 혈액 공급망 예측이 아니다. 원자료·SD·구간·시드는 `examples/experiment-N.json`과 CSV에 있다.
