# 모형 정의와 과학적 범위

기준일 2026-10-21. 하나의 모형 단위는 교육용 물품이며 제제 간 임상적 동등 용량을 뜻하지 않습니다.

| 구분 | 내용 | 근거 또는 가정 |
|---|---|---|
| 선택한 농축적혈구 | 채혈 후 35일, 1–6°C | 대한적십자사 제제 안내의 선택 제품. 모든 적혈구 제품의 공통 기준 아님 |
| 선택한 농축혈소판 | 제조 후 120시간, 20–24°C, 교반 | 같은 안내. 제조 시점은 가상 물품 생성 시점으로 단순화 |
| 동결혈장 | 채혈 후 1년, −18°C 이하 | 같은 안내. 모형은 365일, 동결 상태 공급까지만 계산 |
| RBC 적합성 | ABO 방향과 RhD: 양성→음성 제외, 동일형 우선 | Lifeblood 자료에 근거한 제한된 모형. 추가 항원·교차시험·임상 예외 생략 |
| PLT 적합성 | ABO/RhD 동일형만 허용 | 보수적 연구 가정. 실제 다른 형 수혈 가능 조건과 잔류 적혈구 고려를 생략 |
| FFP 적합성 | ABO 방향은 RBC와 반대, RhD 제한 없음 | Lifeblood. `동일형 제한`은 RhD까지 제한하는 별도 연구 가정 |
| 검사 | 2시간 가상 지연, 모형 처리 용량, 실제 검사 정확도 확률 없음 | 연구 가정. 검사 전 공급 금지 |
| 온도 | 정상값 RBC 4, PLT 22, FFP −25°C 또는 이탈 시 30°C 기록 | 가상 시나리오. 실제 측정·장비 예측·품질 저하식 아님 |
| 온도 보류 | 제제별 범위 이탈 시 보류. 운송에도 보관 범위를 적용 | 실제 운송 허용 판정이 아닌 보수적 가정. 교반 중단은 보관 중 PLT만 대상 |
| 가상 수요 | 6시간마다 포아송. 일별 수요 강도에 평균 보정 로그정규 배율 | volatility는 로그 수요 강도의 표준편차. 실제 수요 추정 아님 |
| 공급 | 혈액원 6시간당 기대 7단위 입고. 초기 78단위 | 고정 가상 값. 초기 연령은 제품 수명의 0–85% 범위 |
| 혈액형·혼합비 | 8종 균등. MIX 생성/수요 비율 RBC 1/2, PLT 1/3, FFP 1/6 | 실제 한국 혈액형·공급·수요 분포 아님 |
| 운송 | OSRM driving 예상시간 × 지연 배율. 경로 길이에 비례한 일정속도 시각화 | 실시간 교통, 실제 혈액 운송 협약·우선통행·출입구는 미확인 |
| 보충 | 기관별 평균 수요×안전재고일수 목표, 제제·혈액형별 입고 예정 포함 | 휴리스틱. 수학적으로 최적이라는 보장 없음 |
| 재배치 | 여유 재고가 있고 해당 병원에 빈 차량이 있을 때 가능 | 기본 차량은 혈액원으로 복귀하므로 재배치 토글이 기본 상황에서 빈번히 작동하지 않을 수 있음 |

`입고 잔여기한` 50%·25%는 가상 시나리오이며 문헌상의 제품 수명을 변경하지 않습니다. 초기 물품과 신규 입고 물품의 남은 기한에 적용합니다. 수요는 해당 6시간 슬롯에서 충족하거나 부족으로 기록하고, 미충족 수요를 다음 슬롯으로 이월하지 않습니다. 만료·검사·보류 물품은 공급에서 제외합니다.

`gate → take → dispatch → arrival`의 상태를 구분합니다. 배송 예약/물품 적재는 목적지 재고가 아닙니다. 도착 전 만료한 물품은 차량에서도 제거되고 폐기로 기록됩니다. 원래 방식의 출고 실패 재고 유실은 rollback으로 막습니다. 보존식은 생성 총량 = 현재 활성 물품 + 공급 완료 + 만료 + 모의 품질 제외 + 모의 검사 제외입니다. 운송·검사·보류 물품은 활성 물품에 정확히 한 번 포함됩니다.

상세 온도 이력은 활성 제제당 최근 80개 표본을, 화면은 그중 최근 24개를 유지합니다. 완료된 제제는 시작·마지막 표본과 최저·최고·이탈 요약, 마지막 사건을 유지해 저장 크기를 제한합니다. 이탈은 안전성 판정이 아니며, 가정상 보류 해제는 연구 기록으로 남습니다. 이탈 상황이 계속되면 다시 보류됩니다.

## 통계

반복 실험은 현재 관제 세계의 설정으로 초기 상태를 다시 생성합니다. 관제 화면의 현재 재고 스냅샷에서 계속 진행하는 실험이 아닙니다.

- 부족률 = 부족 단위 수 / 요청 단위 수. 요청 0이면 미정의.
- 폐기율 = (만료 + 모의 품질 제외 + 모의 검사 제외) / (초기 재고 + 기간 중 입고). 보류는 폐기가 아님.
- 평균 재고 = 시설 내 ready 재고의 시간 적분 / 관측 시간. 운송·검사·보류는 제외.
- 운송시간 = 완료된 적재 운송 구간 시간의 평균. 빈 차 복귀 제외.
- 반복 결과는 **반복별 비율의 산술평균**이며, 모든 반복을 합친 분모의 통합 비율과 구분.
- 표본 SD는 n−1. 95% 구간은 Student t(자유도 n−1, 큰 자유도는 근사) × 표준오차. 비율 차이는 %p.
- 정책 비교는 각 반복의 실험군−기준군 차이를 짝지어 요약. 동일 시드에 동일 초기 재고·외생 공급·수요 난수 흐름. B처럼 수요 강도를 바꾸면 요청량 자체는 달라짐.
- 제품 비교는 수명·적합성·초기 연령 등의 차이가 함께 들어가므로 수명만의 인과효과로 해석할 수 없음. C에서 잔여기한 비율을 단독 변수로 선택하면 다른 조건을 고정한 비교가 가능.
- t 구간은 확률 모형 안의 표본 불확실성이고 실제 예측 정확도가 아님. 작은 반복 수나 치우친 비율에서는 근사 한계가 있고, 계산상 음수 구간도 그대로 표시함.
