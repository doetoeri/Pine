# 전국·지역 공통 모형 2.0

2026-10-22. 실제 의료기관 운영에 사용할 수 없는 교육용 모형이다. 기존 DualWorld, 원래 사건 큐·난수·입고·수요·사용기한·적합성·운송·보류 구조를 확장한다. 인천 4기관의 원자료와 기존 5.1 모델 추출본은 보존했다. 전국 프로토타입의 별도 오버레이·독립 toy 계산은 채택하지 않았다.

## 같은 세계, 다른 관찰 범위

`network=incheon`은 기존 4기관 검증 모형, `network=nationwide`는 100거점(96 가상 + 기존4)이다. 17권역은 최신 법정 구역이 아닌 2021 지리 경계의 고정 연구권역이다. 전국 관제·지역 Engineering·Biology·Research가 한 LabClient/서버 방의 상태를 읽는다. 전국 지도에서 권역 선택은 관찰 범위만 바꾸며 세계를 초기화하지 않는다. 공급망 범위·제제·정책 조건 적용은 초기화이며 화면에 안내한다.

## 공급 정책과 운송 가정

- A: 수요 거점은 같은 권역 공급 거점만 검토한다.
- B: 같은 권역을 우선하고 육지 인접 권역의 후보를 검토한다.
- C: 같은 권역을 우선하고 전국 후보를 검토한다.
- 권역 밖 공급은 공급 권역의 예측 일평균 수요 0.5일분을 남기는 가상 보호 기준을 적용한다. 후보는 이동시간/가상 비용이 작은 순서이며 전역 최적해를 보장하지 않는 탐욕적 정책이다. 제주에는 육지 인접 권역이 없고 C에서만 권역 밖 연결을 검토한다.
- 병원 목표 재고는 안전재고 일수 × 가상 일수요이며 혼합 제제 비율은 RBC 1/2, PLT 1/3, FFP 1/6이다. 공급 가능 재고와 운송 중 목적지 재고를 함께 계산해 같은 부족분에 중복 출발하지 않게 한다. 출고는 FEFO/FIFO와 혈액형 분산을 검토한다.
- 실제 도로 자료는 인천4기관 사이의 저장된 12개 방향 OSRM 경로다. 나머지 구간은 직선거리×1.35 / 60km/h +0.25h, 제주~육지에는 가상6h를 추가한다. 실제 도로·항공·해운 경로나 운항시간이 아니다. 모든 예상시간에 가상 지연 배율을 적용한다. API를 반복 호출하지 않는다.
- 전국 차량은 최대65대·12단위 적재다. 적재 운송 뒤 1시간 후 출발 공급 거점으로 빈 차 복귀한다. 출발지 복귀는 권역 밖 배송이 공급 거점의 차량을 영구적으로 빼앗지 않게 한다. 운송 중 만료·온도 보류는 재고에 그대로 보존·기록한다.
- 가상 운송비 점수는 출발 20 + 지연 적용 전 이동시간×36이다. 원화·실제 운송비·실제 연료비가 아니다. 빈 차 복귀 비용은 점수에서 제외한다.

## 가상 입고·수요

매6시간 입고·수요를 발생시킨다. 인천 기본 모형의 입고는 기존 평균7/슬롯을 유지한다. 전국은 권역별 가상 일수요의1/4 × (0.48 + (공급거점ID×7 mod11)/10)이며 인천2개 공급거점은 각각 절반을 배정한다. 합성 공급 불균형을 만드는 실험 가정이며 한국의 실측 분포를 재현하지 않는다. 검사 처리 용량도 이 모형 규모에 맞춘 가정이고 검사 대기는 최소2시간이다. ABO/RhD는8종 균등 가정이다.

입고·수요·제제 선택 난수는 시드와 시간슬롯·기관·요청 키로 생성한다. 정책별 물류 경로가 수요 난수 호출 순서를 바꾸지 않는다. N 실험은 같은 시드마다 A/B/C를 모두 새 세계로 실행하고 수요 fingerprint와 생성량·보존을 확인한다. A/B/C 기존 연구 실험도 유지한다.

## 분모와 기록

전국 부족률=부족/요청, 전국 폐기율=(만료+품질 제외+검사 제외)/(초기재고+외부 입고). 권역 부족률도 권역 요청량을 분모로 삼는다. 권역 폐기율은 해당 권역 생성량+권역 밖에서 실제 도착한 수량을 분모로 삼는다. 운송 중 만료는 출발 거점에 귀속한다. 권역별 비율의 단순평균은 전국 비율이 아니므로 혼용하지 않는다. 권역 부족률 격차는 수요가 관측된 권역의 최대−최소이며 단위는%p다.

권역 간 운송량·flow는 출발 시 적재 수량이다. imported는 유입 예정 출발량, arrivedImports는 살아 있는 제제가 목적지에 실제 도착한 양이다. 두 값의 차이는 운송 중·만료를 포함할 수 있다. 폐기 분모는 arrivedImports만 사용한다. 공급 가능량은 ready만, 검사·보류·운송은 제외한다. 평균 재고는 시간 적분/관측 시간이다.

반복별 비율의 평균, 표본 SD(n−1), Student t95% 구간을 표시한다. 차이는 B−A/C−A이며 같은 시드끼리 짝짓는다. 기간 종료 시 아직 운송·보관 중인 물품을 폐기나 공급으로 강제 처리하지 않는다. 정책 개선을 사전 지정하지 않는다.

## 생물학적 조건

KRC 선택 제제: 농축적혈구35일·1~6°C, 농축혈소판 제조 후120h·20~24°C·교반, 신선동결혈장1년·−18°C이하. 2026-10-22 공식 페이지 본문을 다시 대조했다. RBC ABO/RhD와 혈장 역방향 ABO를 구분하고 혈소판은 동일형만 허용하는 보수적 교실 모형이다. 실제 교차시험·항체·임상 예외·해동 후 수혈은 생략한다. 운송에도 보관 범위를 적용하는 보수적 가정이다.

온도는 시나리오 기록으로 정상값 또는30°C를 사용한다. 임의의 생존율·용혈률·품질감소 공식을 만들지 않는다. 이탈·교반 중단은 보류를 만들고 실제 사용 가능성은 판정하지 않는다. 사용자의 보류 해제는 교육용 판단 기록이다. 전국의 정상 보존 관찰은6시간 및 출고·도착·만료 시에 기록하고 이탈/교반 시나리오는30분 검토를 유지한다. 동일 온도·단계의 연속 기록은 구간 양 끝점으로 압축하며 최근16점 이내다.

## 성능·저장·검토 한계

전국 재고는 제제·혈액형 색인으로 후보를 찾는다. 완료 물품은 집계·UID 카운터로 보존하고 활성 재고만 유지하며 오래된 만료 사건을 매일 정리한다. JSON은 archivedCount와 활성 물품·미래 사건으로 보존 검증한다. 이전 인천 모형의 단위별 완료 요약은 유지한다.

COMPUTE는 브라우저/Node worker에서 계산한다. 지도는 계산과 분리했고17권역 군집, 확대 시 개별 마커, 화면 밖 차량 생략과20fps 이하 위치 보간을 사용한다. 서버 전송은 권역·제제별 최대40개(보류·만료 임박 우선)의 상세 표본으로 제한하고 전체 활성 수량·권역 지표는 별도로 전송한다. 전체 재고 CSV와 상태 JSON은 별도 export이며 표본을 전체 자료로 제시하지 않는다.

서버는 단일 권위 Node 프로세스·영속 디스크가 전제다. 여러 독립 인스턴스를 같은 방에 붙이는 분산 서버는 미구현이다. 코드6자리는 교육용 초대이며 실제 신원 인증이 아니다. 실제 환자·혈액기관 운영자료를 넣어서는 안 된다. 측정 환경·실제 장치 미검증 범위는 검증 보고서를 따른다.

## 재연결과 서버 실행 식별자

WebSocket 상태는 실험ID·서버 실행UUID(authorityId)·버전·설정 리비전·이벤트ID·시각을 포함한다. 같은 실행UUID 안의 낮은 버전은 버리고 새 서버UUID의 최신 체크포인트는 버전 숫자가 낮더라도 받아들인다. 서버 재시작 때 대기 조작은 취소하고 안내 후 일시정지 상태로 복원한다. 다른 방으로 이동하면 이전 소켓을 닫고 이전 소켓에서 늦게 오는 메시지를 무시한다. 명령은 저장 후 응답하지만 시간 진행은15초 주기 저장이므로 비정상 종료 시 마지막 저장 이후 진행이 손실될 수 있다. 0손실 장애 복구·분산 서버는 구현했다고 주장하지 않는다.
