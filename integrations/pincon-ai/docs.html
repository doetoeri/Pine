PinCon MCP

PinCon의 학교생활 데이터를 AI 플랫폼에서 읽기 전용으로 사용할 수 있는 MCP 서버입니다.

Endpoint

https://pincon-ai.vercel.app/api/mcp

OAuth

공개 연결은 OAuth 2.1 Authorization Code + PKCE(S256)를 사용합니다. 보호 리소스 메타데이터는 /.well-known/oauth-protected-resource, Authorization Server 메타데이터는 /.well-known/oauth-authorization-server에서 제공합니다.

Scope

pincon:read

도구

  • get_today 오늘 브리핑
  • get_timetable 시간표
  • get_meal 급식
  • get_assignments 과제·수행평가
  • get_notices 공지
  • get_school_events 학급·학교 일정
  • get_upcoming 다가오는 일정과 과제

현재 공개 도구는 모두 읽기 전용입니다.
