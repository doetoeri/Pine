감지 방식

웹앱이 주차를 몰래 확정하지 않으며, 항상 확인을 받은 뒤 저장합니다.

자동 주차 제안운전 후 약 1분 이상 정차하면 확인
주차 후 보행 동선차에서 건물까지의 이동도 이어서 기록
추적 중 화면 켜기지원 기기에서만 작동하며 배터리를 더 사용

내 데이터

계정이나 서버를 쓰지 않습니다. 같은 브라우저의 저장 공간에만 남습니다.

주차 기록 보관현재 주차 위치는 직접 지울 때까지 유지

작동 범위

실외 GPS는 주차 건물 위치를, 층·구역·기둥 번호와 사진은 실내 위치를 기억하는 용도예요.
브라우저가 닫히거나 화면이 오래 꺼지면 위치 추적이 멈출 수 있습니다. GPS 권한은 HTTPS 주소(예: GitHub Pages)에서 가장 안정적으로 작동해요.

주차 위치 저장

GPS가 약한 지하에서는 층·구역·기둥 번호와 사진이 특히 유용해요.

위치 확인 중GPS 좌표를 불러오고 있어요.
