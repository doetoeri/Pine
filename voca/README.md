# 의미연결 깜지 생성기

영단어·한글 뜻·영어 예문을 입력해 **보기 → 뜻 인출 → 문맥 인출 → 무힌트 확인** 흐름의 인쇄 학습지를 만드는 오프라인 웹앱입니다. 로그인, 서버, 외부 API가 필요하지 않으며 화면보다 A4/B5 출력의 가독성과 필기 공간을 우선해 설계했습니다.

## 가장 빠른 실행

1. 압축을 푼 폴더에서 `index.html`을 Chrome, Samsung Internet, Edge 중 하나로 엽니다.
2. 처음에는 `샘플` 표시가 붙은 단어 12개가 들어 있습니다. **샘플만 모두 삭제** 버튼으로 한 번에 지울 수 있습니다.
3. **붙여넣기 · 파일 가져오기**에서 텍스트 또는 파일을 넣고 열 매핑 미리보기를 확인합니다.
4. **학습지 구성**에서 유형과 배치를 고른 뒤 오른쪽 미리보기를 확인합니다.
5. **인쇄 · PDF**를 눌러 출력하거나 PDF로 저장합니다.

`index.html`을 직접 여는 방식에서도 입력, 편집, 저장, TXT/CSV/TSV/XLSX 가져오기, 미리보기, 인쇄가 작동합니다. 브라우저 보안 정책 때문에 설치형 PWA와 서비스 워커 캐시는 HTTP/HTTPS로 실행할 때만 활성화됩니다.

## PC에서 실행

### 파일을 직접 열기

`index.html`을 더블클릭합니다. 가장 단순하며 핵심 기능을 모두 사용할 수 있습니다.

### 설치 가능한 앱으로 실행하기

폴더에서 터미널을 열고 다음 중 하나를 실행합니다.

```bash
python -m http.server 8080
```

또는 Windows에서 Python 명령이 `py`인 경우:

```bash
py -m http.server 8080
```

그다음 브라우저에서 `http://localhost:8080`을 엽니다. 브라우저의 설치 아이콘 또는 앱 안의 **앱 설치** 버튼을 사용할 수 있습니다.

## Galaxy Tab·안드로이드 스마트폰에서 사용

### 서버 없이 사용

1. ZIP 압축을 내 파일 앱에서 풉니다.
2. `index.html`을 누르고 Chrome 또는 Samsung Internet으로 엽니다.
3. 파일 URL에서 브라우저 저장이 제한되는 환경이면 아래 HTTP 방법을 사용합니다.

### PC와 같은 Wi-Fi에서 사용

1. PC의 앱 폴더에서 `python -m http.server 8080`을 실행합니다.
2. PC의 로컬 IP를 확인합니다. 예: `192.168.0.12`.
3. Galaxy Tab에서 `http://192.168.0.12:8080`을 엽니다.
4. Chrome 메뉴의 **홈 화면에 추가** 또는 앱의 **앱 설치**를 누릅니다.
5. 한 번 정상 접속한 뒤에는 저장된 앱 셸이 오프라인에서도 열립니다.

Galaxy Tab 가로 화면에서는 편집과 미리보기가 나란히 보입니다. 스마트폰 폭에서는 상단의 **편집 / 미리보기** 탭으로 전환합니다.

## 데이터 가져오기

- 직접 입력: **빈 행 추가** 후 각 칸을 수정합니다.
- 붙여넣기: `단어 | 뜻 | 예문` 또는 엑셀에서 복사한 탭 구분 표를 붙여넣습니다.
- 파일: `.txt`, `.csv`, `.tsv`, `.xlsx`, `.xls`의 첫 시트를 읽습니다.
- 열 매핑: 가져오기 전 각 열을 영단어·뜻·예문·Day·단원·과·태그에 연결하고 최대 10행을 미리 확인합니다.
- 백업: **전체 JSON 내보내기**로 단어와 설정을 한 파일에 저장하고 다시 불러올 수 있습니다.

셀 안의 쉼표와 줄바꿈을 포함하는 표준 CSV 따옴표 형식을 지원합니다. 입력된 철자, 뜻, 문장부호는 자동 교정하거나 임의 생성하지 않습니다.

## 학습지 유형

- **A 학습형**: 단어·뜻·예문을 보며 따라 씁니다. 필기선의 연한 힌트 농도를 조절할 수 있습니다.
- **B 인출형**: 뜻과 빈칸 예문만 보고 영어 단어를 씁니다. 예문에서 정확한 단어를 찾지 못하면 원문을 유지하고 별도 응답 빈칸을 붙입니다.
- **C 시험형**: 뜻·빈칸 예문·채점 체크칸을 제공하며, 기본적으로 순서를 섞고 정답지를 포함합니다.
- **D 단계혼합형**: 한 단어마다 보기, 뜻, 빈칸 문맥, 무힌트의 네 단계를 연속해 연습합니다.

## PDF로 선명하게 저장

1. 앱에서 **인쇄 · PDF로 저장**을 누릅니다.
2. 인쇄 대상을 **PDF로 저장**으로 선택합니다.
3. 용지 크기는 앱에서 선택한 A4 또는 B5와 같게 설정합니다.
4. 배율은 **기본값(100%)** 또는 **실제 크기**를 사용합니다.
5. 브라우저의 머리글과 바닥글 옵션은 끄는 것을 권장합니다.
6. 배경 그래픽을 꺼도 핵심 내용과 필기선은 남지만, 연한 보조 면까지 동일하게 보이려면 배경 그래픽을 켭니다.

학습지는 HTML 텍스트와 CSS 선으로 구성되므로 브라우저의 PDF 저장 과정에서 글자가 가능한 한 벡터 텍스트로 유지됩니다. PNG나 캔버스 이미지로 변환하지 않습니다.

## 자동 저장과 개인정보

- 단어 목록과 학습지 설정은 현재 브라우저의 `localStorage`에 자동 저장됩니다.
- 서버로 전송되는 데이터가 없으며 외부 AI/API도 호출하지 않습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 앱 폴더 이동 시 데이터가 사라질 수 있으므로 중요한 목록은 JSON으로 백업하세요.

## 구현된 기능

- 직접 입력, 다중 텍스트 붙여넣기, TXT/CSV/TSV/XLSX 가져오기
- 구분자·제목행 자동 감지, 열 매핑, 가져오기 미리보기, 추가/교체
- 행 추가·수정·삭제·복제·위아래 이동, 선택 일괄 삭제
- Day·단원 필터와 전체 검색
- A/B/C/D 네 가지 학습지, 안정적인 예문 빈칸 처리, 정답지
- A4/B5, 세로/가로, 1단/2단, 쪽당 단어, 반복, 글씨, 칸 높이, 간격, 여백, 힌트 농도 설정
- 실제 mm 단위 페이지, 높이 측정 기반 자동 페이지 나눔, 잘림 진단
- 화면 맞춤 미리보기와 페이지 수 표시
- 인쇄 전용 CSS, 동적 `@page`, 화면 도구 완전 숨김
- 자동 저장, JSON 백업/복원, 화면 다크 모드
- 외부 CDN 없는 오프라인 자산, manifest와 service worker
- Galaxy Tab·스마트폰·PC 반응형 UI와 44px 이상 주요 터치 대상

## 의도적으로 제외한 기능

로그인, 계정, 클라우드 동기화, 공동 편집, 결제, OCR, AI 예문 생성, 관리자 페이지, 통계 대시보드, 백엔드 데이터베이스는 포함하지 않았습니다.

## 알려진 제한 사항

- PWA 설치와 서비스 워커는 브라우저 정책상 `file://`이 아닌 HTTP/HTTPS 환경이 필요합니다.
- Android 브라우저에서 로컬 HTML을 여는 방식은 제조사 파일 앱과 브라우저 조합에 따라 `localStorage` 유지 정책이 다를 수 있습니다. 이 경우 HTTP 실행을 사용하세요.
- 브라우저 인쇄 대화상자의 용지 설정이 앱과 다르면 축소되거나 빈 여백이 생길 수 있습니다.
- 사용자가 글씨와 필기 칸을 매우 크게 만들고 한 항목에 극단적으로 긴 문장을 넣으면 한 항목이 한 페이지보다 커질 수 있습니다. 앱이 이를 **배치 확인 필요**로 표시하며, 항목을 반으로 자르지는 않습니다.
- XLSX는 첫 번째 시트만 가져옵니다. 수식은 계산식 자체가 아니라 파일에 저장된 표시 값을 읽습니다.

## 파일 구성

- `index.html` — 실행 진입점과 접근 가능한 UI
- `styles.css` — 화면, 반응형, 실제 용지, 인쇄 전용 스타일
- `app.js` — 편집, 가져오기, 저장, 학습지 생성, 페이지 나눔
- `manifest.webmanifest`, `sw.js`, `icons/` — 설치, 오프라인 캐시, 홈 화면 아이콘
- `fonts/` — 기기 글꼴이 없어도 한글이 깨지지 않게 하는 로컬 Noto Sans KR 가변 글꼴과 라이선스
- `sample-words.tsv` — 12개 검증용 샘플
- `vendor/xlsx.full.min.js` — 로컬 XLSX 읽기 모듈
- `vendor/XLSX-LICENSE.txt` — XLSX 모듈 라이선스
- `tests/` — 검증 스크립트와 결과 기록

## 호환 기준

Galaxy Tab/Samsung Internet과 Android Chrome의 최신 안정 버전, 데스크톱 Chrome·Edge를 우선 대상으로 합니다. 앱은 현대 브라우저의 `dialog`, `CSS Grid`, `localStorage`, Blob 다운로드 기능을 사용합니다.

## 검증 결과

실제 Chromium으로 파일 업로드, 버튼 조작, 새로고침, 30개 장문 페이지 분할, 모바일·태블릿·PC 반응형, 인쇄 PDF, 서비스 워커 오프라인 재접속을 자동 검증했습니다. 최종 결과는 **17개 통과, 실패 0개, 치명적 콘솔 오류 0개**이며 상세 기록은 `tests/TEST-RESULTS.md`에 있습니다.
